# The landscape of tissue-resident microbiota across normal, polyp, and colorectal cancer tissues

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18015706.svg)](https://doi.org/10.5281/zenodo.18015706)

This repository contains the raw code and processed data associated with the research article: **"The landscape of tissue-resident microbiota across normal, polyp, and colorectal cancer tissues"**.

## 📌 Overview

This project analyzes the microbiome composition differences across different tissue types (Normal, Polyp, and CRC). All analyses were performed using R. The scripts provided here reproduce the figures and statistical analyses reported in the manuscript.

## 📂 Repository Structure

The repository is organized as follows:

- **`data/`**: Contains the input data and processed R data files (e.g., `.rds`, `.RData`, or CSVs) used for downstream analysis.
- **`scripts/`**: Contains all R scripts used to generate the plots and perform statistical tests presented in the article.
